## English (United States)

### Short description

Switch the IME with a tap of the Alt or Windows key, while shortcuts like Alt+Tab keep working.

### Description

Outatime Switcher switches the IME when you tap Alt or the Windows key on its own. Give each of the four keys its own action: toggle the IME, turn it on, or turn it off. For example, tap Left Alt to type in English and Right Alt to type in Japanese, Korean or Chinese.

Only a lone tap counts, so Alt+Tab, Win+E and other shortcuts work as usual, and a tap doesn't open the menu bar or the Start menu. Tap the same key twice quickly to undo the switch and get the key's usual action.

It runs quietly in the notification area and pauses in full-screen games, or in any full-screen app if you prefer. Changes in the settings app apply right away.

To start it automatically, turn on "Start at sign-in" in the settings. To open the settings, start Outatime Switcher again from the Start menu, or right-click its icon in the notification area.

Notes:
- Windows doesn't let a regular app see keys typed into apps running as administrator, so tapping does nothing in them.
- When you use the PC through a remote desktop app, turn on "Respond to keys sent by other apps".

Outatime Switcher doesn't collect any data or connect to the internet. It's open source under the MIT License.

### Product features

- Tap Alt or the Windows key on its own to switch the IME
- Choose an action for each key: toggle the IME, turn it on, or turn it off
- Shortcuts like Alt+Tab and Win+E keep working
- Double-tap a key for its usual action
- Pauses in full-screen games
- Lightweight, runs in the notification area
- Available in English, Japanese, Korean and Chinese

## 日本語 (日本)

### 短い説明

Alt キーや Windows キーを単独で押すだけで IME を切り替えます。Alt+Tab などのショートカットはそのまま使えます。

### 説明

Outatime Switcher は、Alt キーや Windows キーを単独で押したときに IME を切り替えるアプリです。左右の Alt キーと Windows キーの 4 つに、「IME を切り替える」「IME をオン」「IME をオフ」をそれぞれ割り当てられます。たとえば、左 Alt で英数入力、右 Alt でかな入力にできます。

反応するのは単独で押したときだけなので、Alt+Tab や Win+E などのショートカットは普段どおり使えます。押してもメニュー バーやスタート メニューは開きません。同じキーを素早く 2 回押すと、切り替えを取り消して、キー本来の動作になります。

通知領域で静かに動き、全画面のゲームでは一時停止します。すべての全画面アプリで一時停止することもできます。設定アプリでの変更はすぐに反映されます。

自動で起動するには、設定の「サインイン時に起動」をオンにしてください。設定を開くには、スタート メニューから Outatime Switcher をもう一度起動するか、通知領域のアイコンを右クリックします。

注意点:
- Windows では、普通のアプリは管理者として実行中のアプリへのキー入力を受け取れないため、そうしたアプリでは反応しません。
- リモート操作アプリでこの PC を操作するときは、「ほかのアプリから送信されたキー入力にも反応する」をオンにしてください。

Outatime Switcher はデータを収集せず、インターネットにも接続しません。MIT ライセンスのオープンソース ソフトウェアです。

## Submission options

In English, for the Store's testers.

### Notes for certification

Outatime Switcher switches the IME when the user taps Alt or the Windows key on its own. It has no window of its own at first: it runs in the notification area.

How to test:

1. Add an IME that has an on/off state, such as Japanese (Settings > Time & language > Language & region > Add a language > Japanese), and select it as the input method.
2. Start Outatime Switcher from the Start menu. An icon appears in the notification area. Start it again from the Start menu, or click the icon, to open the settings app.
3. Open Notepad and tap Left Alt: press and release it without pressing any other key. The IME switches between Japanese input and alphanumeric input each time, and the menu bar doesn't open.
4. Alt+Tab and other shortcuts work as usual. Tapping Left Alt twice quickly gives Alt's usual action instead.
5. In the settings app, the other keys (Right Alt, Left Windows, Right Windows) can be given an action too. Changes apply right away.

Known limitation: Windows doesn't let a regular app see keys typed into apps running as administrator, so tapping does nothing in them.

### Why runFullTrust is needed

The field takes about 500 characters.

Its core function needs Win32 APIs that aren't available in an app container: a low-level keyboard hook (WH_KEYBOARD_LL) notices lone taps of Alt or a Windows key anywhere in Windows; SendInput keeps the tap from opening the menu bar or the Start menu; WM_IME_CONTROL to the foreground window's IME window turns its IME on or off. Keystrokes are never recorded or sent, and the app has no network access. Source: https://github.com/yk4to/outatime
